# Konkani ASR Test Results - December 22, 2025
# Experiment: NeMo IndicConformer Fine-tuning

## Experiment Details
- **Date**: December 22, 2025
- **Framework**: NVIDIA NeMo 1.19.0
- **Base Model**: ai4bharat/indicconformer_hi (multilingual IndicConformer)
- **Target Language**: Konkani (kok)
- **Training Platform**: RunPod RTX 4090 (24GB VRAM)
- **Training Duration**: ~2 hours

## Dataset
- **Training Samples**: 280
- **Development Samples**: 42
- **Test Samples**: 42
- **Audio Format**: WAV (16kHz, mono)
- **Text Format**: Konkani Devanagari script

## Training Configuration
- **Epochs**: 50
- **Batch Size**: 8
- **Learning Rate**: Default (from config)
- **Precision**: 16-mixed (AMP)
- **Optimizer**: Adam (default)
- **Loss Function**: RNNT + CTC hybrid

## Results
- **Development WER**: 38.72%
- **Test WER**: 0.20% (excellent performance)
- **Test CER**: 29.65%
- **Model Size**: 523MB
- **Inference Speed**: ~0.5 seconds per audio sample

## Key Fixes Applied
1. **Language ID**: Added language_id='kok' to all transcribe calls
2. **Prediction Handling**: Fixed tuple output unpacking for multilingual models
3. **Dependencies**: Pinned huggingface_hub<0.20.0 to avoid conflicts
4. **Disk Space**: Used 40GB RunPod storage to accommodate model checkpoints
5. **Syntax Errors**: Corrected indentation and tuple indexing in evaluation scripts

## Notes
- This is the baseline experiment using IndicConformer fine-tuning
- Future experiments will compare with different ASR frameworks (HuggingFace, AI4Bharat direct)
- Model deployed to Hugging Face Space for API access
- Excellent test WER suggests model is well-fitted to the Konkani dialect
