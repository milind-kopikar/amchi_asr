Implementation Plan: Cloud GPU Development Environment
1. Context & Goal
Current State: Coding locally on a Windows laptop using VS Code + GitHub Copilot.

Problem: The machine learning workload requires a Linux environment and a powerful GPU (Nvidia), which the local laptop lacks.

Goal: Establish a low-cost (<$10/month), ephemeral cloud environment that supports heavy GPU workloads while maintaining the "Agentic Coding" experience (seamless GitHub Copilot access) from the local VS Code editor.

Constraint: Must be economical. Avoid complex "Hyperscaler" (AWS/GCP/Azure) billing risks and setup overhead.

2. The Recommended Architecture
We will use a Hybrid Approach to balance cost, persistence, and performance.

Compute (RunPod): An on-demand GPU instance (e.g., RTX 3090/4090) for training/coding.

Cost: ~$0.30–$0.40/hour.

Usage: Turn ON when working, Turn OFF when sleeping.

State/Data (Railway): Continue using the existing PostgreSQL database.

Cost: $5/month (existing).

Usage: Always on, persistent storage for app data.

Interface (VS Code Remote - SSH): Connects the local Windows IDE to the remote RunPod Linux server.

3. The Implementation Steps
Phase A: Prerequisites (One-Time Setup)
Generate SSH Key (Local Windows):

Open PowerShell.

Run: ssh-keygen -t ed25519 (Press Enter through prompts).

Run: cat ~/.ssh/id_ed25519.pub and copy the output string.

RunPod Account:

Create an account on RunPod.io.

Add at least $10 in credits (Hard limit to prevent overspending).

Add your SSH Key (from step 1) in Settings > SSH Public Key.

Phase B: Provisioning the Environment
Deploy Pod:

Select Community Cloud.

GPU: RTX 3090 or RTX 4090.

Template: RunPod PyTorch 2.x (Pre-installed drivers/Python).

Click Deploy.

Get Connection Details:

Once "Running," click Connect.

Copy the SSH command (IP address, Port, User root).

Phase C: Connecting the IDE (VS Code)
Install Extension: Install Remote - SSH (Microsoft) in VS Code.

Connect:

Click the green/blue >< icon (bottom-left).

Select Remote-SSH: Connect to Host... > Add New Host.

Paste the SSH command from RunPod (e.g., ssh root@123.45.67.89 -p 10001).

Launch Window: Connect to this new host. A new VS Code window will open representing the remote machine.

Phase D: Enabling "Agentic" Capabilities
Install Copilot on Remote:

In the remote VS Code window, go to the Extensions tab.

Find GitHub Copilot (it will be grayed out/uninstalled in the "SSH" section).

Click "Install in SSH: ...".

Authenticate: Follow the prompt to sign in to GitHub if requested.

4. Verification & Testing
Run these tests to ensure the system is ready for work.

Test 1: GPU Visibility

Open the terminal in the remote VS Code window (Ctrl + ~).

Run: nvidia-smi

Success: You should see a table listing the GPU (e.g., NVIDIA GeForce RTX 3090) and CUDA version.

Test 2: Copilot Integration

Create a file named test_gpu.py.

Type a comment: # Write a script to check if pytorch can see the cuda device.

Success: Copilot should autocomplete the code.

Test 3: Execution

Run the script generated by Copilot.

Success: Output should be True or cuda.

5. Daily Workflow (Cost Saving)
Start: Log in to RunPod -> Start Pod -> Open VS Code -> Reconnect.

Stop (CRITICAL): When finished for the day, go to RunPod Dashboard -> STOP the pod.

Note: While stopped, you pay a tiny fee for disk storage (pennies), but $0 for the GPU.

Destroy: When the project is 100% complete, Terminate/Delete the pod to stop all charges.
